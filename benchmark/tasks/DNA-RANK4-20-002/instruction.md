# Prompt

## Context

HLA associations are studied in type 1 diabetes families of European ancestry. The following DRB1–DQA1–DQB1 haplotypes occur on the same chromosome and use two-field HLA allele nomenclature. Compare haplotypes carried by affected offspring with those not transmitted to affected offspring.

## Question

Rank the following haplotypes by their associated risk of type 1 diabetes, from highest to lowest. Return one JSON array containing the four letters in ranked order, e.g. ["A", "B", "C", "D"].

## Options

A. DRB1*04:01–DQA1*03:01–DQB1*03:02
B. DRB1*15:01–DQA1*01:02–DQB1*06:02
C. DRB1*03:01–DQA1*05:01–DQB1*02:01
D. DRB1*07:01–DQA1*02:01–DQB1*02:01
